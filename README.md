# [9craft][5]

![9craft logo](9craft%20Logo.png)

[Website][5]

A suite of Minecraft server ([PaperMC][6]) plugins.

## 9craft Map

A PaperMC plugin that provides a web map for Minecraft servers.

## 9craft Web Server

A PaperMC plugin that provides a web server other plugins can integrate with.
