A suite of [PaperMC][5] server plugins.

## Yggdrasil Data

A Paper plugin that provides an ORM and database connection pool to other
plugins.

## Yggdrasil Map

A Paper plugin that provides a web map for Minecraft servers.

## Yggdrasil Web Server

A Paper plugin that provides a web server to other plugins.
